# Skill: answer-question

## Purpose

Answer natural-language questions from stored knowledge.

## Input

- question text
- relevant objects (sources, captures, ideas, summaries)

## Output

- concise answer
- citations by object ID
- confidence
- follow-up questions or caveats

## Instructions

- Use only stored objects; do not hallucinate.
- Cite specific object IDs.
- Distinguish source claims from Ethan's position.
- Say "I don't know" or "not found" when appropriate.
- Suggest related objects when useful.

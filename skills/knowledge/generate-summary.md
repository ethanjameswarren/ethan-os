# Skill: generate-summary

## Purpose

Generate or refresh the canonical summary for a source or topic.

## Input

- source object
- related captures and ideas
- optional topic

## Output

- summary object with three sections:
  - `## 30 Seconds`
  - `## 5 Minutes`
  - `## Detailed Personal Summary`

## Instructions

- 30 Seconds: only the most important takeaway.
- 5 Minutes: major concepts, Ethan's interpretation, disagreements, applications.
- Detailed: source arguments, interpretation, examples, disagreements, open questions, connections, applications, changes in thinking.
- The summary must be personal, not generic SparkNotes.
- Preserve source/user separation.

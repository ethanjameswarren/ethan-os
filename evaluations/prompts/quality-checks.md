# Quality Check Prompts

Use these prompts to evaluate AI-generated outputs.

## Capture fidelity

Review the raw capture and the generated objects. Did the system preserve the user's original meaning? Did it add interpretation that belongs in a separate field?

## Source / user separation

Identify at least one source claim, one interpretation, and one position field. Are they clearly distinct?

## Relationship quality

For each typed relationship, is there a contextual justification beyond keyword similarity?

## Summary usefulness

Does the summary answer "what would change if Ethan actually understood or believed this?" Does it contain personal interpretation, disagreement, and applications?

## Excessive objects

Are there objects that could have been combined or omitted?

# Career Domain Examples

## Capture

> at acme corp i led the migration of our reporting pipeline to airflow. it used to be a tangle of cron jobs nobody trusted. i redesigned the DAGs, added data quality checks, and got the on-call team to stop getting paged every morning.

## Resulting objects

- Career Evidence: "Reporting Pipeline Migration — Acme Corp"
  - facts: led migration, redesigned DAGs, added data quality checks, reduced on-call pages
  - skills: data engineering, orchestration, stakeholder trust-building
  - technologies: Airflow
  - resume_candidates: "Led migration of a legacy cron-based reporting pipeline to Airflow, adding data quality checks and eliminating recurring on-call incidents."

## Job Target

Pasted job description for "Senior Data Engineer" at a fictional company produces a Job Target with:

- requirements categorized (technical/critical: Airflow experience; leadership/important: mentoring junior engineers)
- hiring_intent: "modernize unreliable batch pipelines and reduce operational burden"

## Resume

`build-tailored-resume` matches the Airflow migration evidence to the Airflow requirement as a **strong direct match**, selects it as a top bullet, and links it back to the Career Evidence object via `evidence_ids`.

## Interview Prep

The same evidence is reused to generate a STAR story under the `technical_leadership` category, referencing the same `evidence_ids` used in the resume.

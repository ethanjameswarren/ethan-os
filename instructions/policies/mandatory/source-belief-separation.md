# Mandatory Source / Belief Separation Policy

The system must separately represent what a source claims and what Ethan believes.

## Rules

- Source claims are recorded as source claims.
- Ethan's interpretation is recorded separately.
- Ethan's position (agree / disagree / neutral / exploring) is recorded explicitly.
- Confidence is recorded explicitly.
- Supporting and contradicting evidence can be noted.
- Never infer Ethan believes something merely because a source says it.

# Mandatory Provenance Policy

Every object generated by Ethan OS must have traceable provenance.

## Required provenance fields

- `capture_id`: the raw capture that produced the object, if any
- `source_id`: the source the object relates to, if any
- `agent_version`: the OS version or skill that produced it
- `provenance_note`: human-readable origin description

## Rules

- If provenance is unclear, flag the object for review. Do not invent origin.
- Generated objects must preserve links to their originating captures and sources.
- Provenance is mandatory; absence blocks write.

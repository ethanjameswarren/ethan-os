# Mandatory Privacy Policy

Real personal information belongs only in `ethan-life`.

## Rules

- `ethan-os` must not require real personal data to function or demonstrate its architecture.
- `ethan-os` tests and fixtures use fake/demo data only.
- `ethan-os` may read `ethan-life` when explicitly invoked, but must not store that data inside `ethan-os`.
- `ethan-life` must remain private.

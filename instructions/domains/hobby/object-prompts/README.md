# Hobby Object Prompts

This directory holds object-prompt templates for hobby-domain structured captures. Add prompt fragments here when conversational creation of `hobby.collection-item`, `hobby.session`, `hobby.battle-report`, `hobby.lore-candidate`, `hobby.lore-canon`, `hobby.lore-book-section`, `hobby.lore-book-edition`, `hobby.media`, or `hobby.narrative` objects requires fine-grained instructions beyond the domain instructions.

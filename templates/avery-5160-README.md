# Ethan OS Avery 5160 Label Template

Canonical LaTeX template for the physical record-labeling capability
(`workflows/music/print-record-labels.md`, `skills/music/render-avery-5160-sheet.md`).

## Files

- `avery-5160-sheet.tex` — a worked example print batch (two real releases, `RYCL016` and
  `SK11X015`, from Ethan's collection). Real batches generated by `print-record-labels` are
  written to `ethan-life/data/music/record-collection/print-batches/<batch_id>/sheet.tex`, not to
  this file — this is the reusable starting point/reference, not a canonical batch.
- `avery-5160.sty` — centralized geometry and typography for Avery 5160 US Letter sheets (30
  labels/sheet, 3 columns x 10 rows).

## Geometry (Avery 5160, US Letter)

| Dimension | Value |
|---|---|
| Sheet | 8.5in x 11in |
| Labels per sheet | 30 (3 columns x 10 rows) |
| Label size | 2.625in x 1.0in |
| Top margin | 0.5in |
| Left margin | 0.1875in |
| Column pitch (label + gutter) | 2.75in |
| Row pitch | 1.0in (no vertical gutter) |
| Inner text inset | 0.09in |

These are the standard, widely published Avery 5160 dimensions. **This has not been compiled or
test-printed in this environment** (no LaTeX toolchain was available when it was built) — do a
first alignment test print on plain paper (enable `\ShowLabelGuides` to see the label cell
borders) before printing onto real Avery sheets, and adjust `avery-5160.sty` if your printer's
margins differ.

## How a print batch is generated

```
Canonical data (albums.csv, tracks.csv) → evaluate-label-readiness → render-avery-5160-sheet → sheet.tex → PDF (if the environment supports LaTeX compilation)
```

Content and presentation stay separate, exactly like the resume template:

```latex
\usepackage{avery-5160}
\LabelStartAt{8}        % supports partially-used sheets; omit to start at position 1
\begin{document}
\PrintLabel{ ... }      % one call per physical label, in canonical order
\end{document}
```

`\PrintLabel` auto-advances through the 30 grid positions and inserts a page break whenever
wrapping to a new sheet. `render-avery-5160-sheet` (not this style file) decides:

- which fields to include and how to handle blanks (e.g. omitting the `Year -` prefix if `Year`
  is blank),
- the print-time tag/comment shortening described in `instructions/domains/music/instructions.md`,
- canonical album-label-then-its-tracks ordering, and release grouping when multiple releases
  share a sheet.

## Content helpers (`avery-5160.sty`)

- `\LabelTitle{}` — bold header line (album `Year - Album`, or track `Energy - Track`).
- `\LabelMeta{}` — secondary line (album `Release | Label`, or track `Artist`).
- `\LabelBody{}` — small body text (BPM/Energy/Rating line, tags, comment).

These are plain typographic helpers; they do not decide content, matching `ethan-resume.sty`'s
separation of presentation from content.

## Customization

Adjust presentation globally in `avery-5160.sty`: font sizes, `\AveryInset` padding, or the
geometry lengths if you switch to a different Avery SKU. Do not embed record-specific content
into the style file — that belongs in a generated batch `.tex` file.

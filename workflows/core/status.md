# Workflow: status

## Purpose

Show concise operational state.

## Steps

1. Scan `ethan-life/inbox/` and `ethan-life/domains/knowledge/`.
2. Collect:
   - recent captures
   - sources in progress
   - recently created ideas
   - items needing review
   - unresolved processing issues
3. Summarize in a short report.

## Output

- status report (plain text)

## Confirmation policy

- Read-only workflow: no confirmation required.
